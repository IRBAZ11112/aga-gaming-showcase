# AGA Gaming — Boutique en ligne

Boutique en ligne développée pour **AGA Gaming**, un magasin gaming.
Le site permet aux clients de passer commande à distance, qu'ils habitent loin du magasin physique ou dans la même ville.

> Le code source de ce projet est privé (propriété du client). Ce dépôt présente le projet, ses fonctionnalités et les technologies utilisées.
